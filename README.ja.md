# Hairstyle Try-on · ヘアスタイルのバーチャル試着

[English](README.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [Français](README.fr.md) | [Português](README.pt.md) | [Русский](README.ru.md) | [한국어](README.ko.md) | 日本語

自撮り写真をもとに、実現しやすいヘアスタイルを提案し、髪型を変えたイメージを試せる Codex スキルです。

自撮り写真を用意し、希望があれば目標のヘアスタイル写真も添付してください。Codex が髪の状態や普段のスタイリング習慣に合わせて、4–6種類の完成したスタイル案を提案します。気に入った案を複数選ぶと、内蔵 imagegen で各案の試着画像を1枚ずつ生成し、比較ページと美容師に見せられるわかりやすい希望メモを作成します。

## 進め方

1. 鮮明な正面の自撮り写真を用意します。横・後ろからの写真や、目標のヘアスタイル写真は任意です。
2. 髪の状態、パーマ・カラーの可否、毎日のスタイリングに使える時間、避けたいことを選択肢で回答します。「わからない」や自由記述でも回答できます。
3. 参考画像、おすすめする理由、実現に必要な条件、出典リンク付きの候補を確認します。
4. 標準では1–3案を選び、各案につき1枚の画像を生成します。明示的に依頼すれば、さらに多くの案を選べます。
5. 個別の画像と横並びの比較を確認し、スタイルIDを指定して調整を依頼します。

スタイルは性別を問わず、長さや特徴で整理します。目標の写真がある場合は、ご本人の髪の条件に合わせて調整します。生成のたびに元の自撮り写真を使い、ご本人の外見の基準とします。

## 動作要件

このリポジトリにはスキルの指示が含まれており、画像モデル、APIサービス、プラグインの実装は含まれていません。ローカルスキルの実行、画像の閲覧、内蔵 imagegen の呼び出しに対応した Codex 環境が必要です。

| ツール | 用途 | 利用できない場合 |
| --- | --- | --- |
| Codex 内蔵 imagegen | 試着画像の生成・編集 | 提案した案を保持して制限を説明します。有料APIへ自動で切り替えることはありません |
| Exa（任意） | ヘアスタイルの情報源の検索・閲覧に優先して使用 | 通常のウェブ検索に切り替えます |
| TypeSafe（任意） | 候補の説明文の選別・順位付け | Codex が選別します |
| Interactive Form Save（任意） | 条件の入力、複数選択、送信された回答の読み取り | 番号付きの選択肢と自由記述を使います |

内蔵 imagegen を使う場合、`OPENAI_API_KEY` の設定は不要です。外部ツールの利用可否、利用上限、利用規約は各サービスに従います。このリポジトリに、それらのサービスへのアクセス権は付属していません。

## インストール

このリポジトリを `hairstyle-tryon` フォルダとしてクローンまたは展開し、Codex に設定されている skills ディレクトリに配置します。

```text
skillsディレクトリ/
└── hairstyle-tryon/
    ├── SKILL.md
    ├── README.md
    ├── README.zh-CN.md
    ├── README.es.md
    ├── README.fr.md
    ├── README.pt.md
    ├── README.ru.md
    ├── README.ko.md
    ├── README.ja.md
    └── LICENSE
```

`CODEX_HOME` が設定されている場合は、その配下の `skills` ディレクトリを利用できます。インストール前に同名のフォルダがないか確認し、既存の変更を残してください。`hairstyle-tryon` フォルダが二重に入れ子にならないようにします。

## 使い方

Codex でスキルを呼び出し、写真を添付します。例：

```text
$hairstyle-tryon で、普段の通勤に合うヘアスタイルを探して。
今の髪色を維持し、パーマはかけず、毎日のスタイリングは5分くらいにしたい。
正面の自撮り写真を添付するので、先に複数の案を選ばせてから試着画像を生成して。
```

目標のヘアスタイル写真がある場合は一緒に添付し、特に残したい特徴を伝えてください。その後は「H02の前髪を少し短くして、ほかはそのままにして」のように変更を依頼できます。

## 成果物

標準では、タスクの作業領域にある `output/hairstyle-tryon/<実行ごとの一意なID>/` に保存します。別のディレクトリを指定することもできます。

- スタイルIDとバージョンで命名した、各案の試着画像。
- `comparison.html`：元の写真と生成画像を参照して、横並びで表示する比較ページ。
- `notes.md`：出典、生成プロンプト、確認結果、各スタイルの希望メモ。

ヘアスタイルの希望メモは、美容師にそのまま見せられる平易な説明です。残したい特徴、受け入れられる変更、普段のスタイリング習慣、対面で確認すべき条件をまとめます。具体的なカット技術の指示や、仕上がりを保証するものではありません。

## 検証状況と画像の取り扱い

現在のスキルのバージョンは `v0.1.0` です。スキルの構造チェックは通過していますが、実際の自撮り写真を使った画像生成の全工程はまだ検証していません。生成画像は見た目の参考として使用してください。実際にその髪型にできるかどうかは、対面で髪の状態を確認して判断する必要があります。外見の保持はプロンプトでの制約と目視確認によって行い、ピクセル単位で変わらないことは保証しません。

リポジトリにはスキルと文書のみが含まれ、ユーザーの自撮り写真や第三者の参考画像は含まれていません。実行時に提供された写真は、その依頼にのみ使用します。変更を公開する前にコミット対象のファイルを確認し、写真、生成結果、認証情報を含めないようにしてください。出力フォルダと一般的なローカル入力フォルダは `.gitignore` で除外されています。
