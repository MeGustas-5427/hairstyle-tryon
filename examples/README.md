## Checks & scope · 检查范围

All 16 source files were checked against the completed test deliveries before conversion. For faster loading, the gallery uses lossy WebP copies (quality 88), with the original pixel dimensions, aspect ratios and embedded color profiles preserved. Total image size dropped from 22.26 MiB to 1.48 MiB (93.35% smaller). All WebP files were decoded and checked for matching dimensions; selected images were visually inspected. The original JPEG/PNG files remain in the local test deliveries. No new portraits, cropping or retouching were added for publication. The superseded P02 generation and unselected candidates are excluded.

16 个源文件在转换前已与本地测试交付核对。图库使用 WebP 有损压缩副本（质量 88），保留原始像素尺寸、比例及内嵌色彩配置，总体积从 22.26 MiB 降至 1.48 MiB，减少 93.35%。所有 WebP 均已检查解码与尺寸，并抽查视觉效果；原始 JPEG/PNG 保留在本地测试交付中。发布时未重新生成、裁切或修饰人像，已排除 P02 的作废生成和未选候选。未验证用户本人自拍、真实剪染效果或量化身份保持指标。
