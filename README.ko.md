# Hairstyle Try-on · 헤어스타일 가상 체험

[English](README.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [Français](README.fr.md) | [Português](README.pt.md) | [Русский](README.ru.md) | 한국어 | [日本語](README.ja.md)

셀카를 바탕으로 현실적인 헤어스타일을 추천하고, 바꾼 모습을 미리 볼 수 있는 참고 이미지를 만드는 Codex 스킬입니다.

셀카를 제공하고, 원한다면 목표 헤어스타일 사진도 함께 첨부하세요. Codex가 모발 상태와 평소 손질 습관에 맞춰 4–6개의 완성된 스타일을 추천합니다. 마음에 드는 스타일을 여러 개 선택하면 내장 imagegen으로 스타일별 참고 이미지를 한 장씩 생성하고, 비교 페이지와 미용사에게 보여줄 쉬운 말로 된 요청 카드를 함께 제공합니다.

## 진행 과정

1. 선명한 정면 셀카를 제공합니다. 옆모습, 뒷모습, 목표 헤어스타일 사진은 선택 사항입니다.
2. 모발 상태, 펌·염색 허용 여부, 매일 손질에 쓸 수 있는 시간, 피하고 싶은 사항을 선택지로 답합니다. “잘 모르겠어요”를 선택하거나 자유롭게 설명해도 됩니다.
3. 참고 이미지, 추천 이유, 구현에 필요한 조건, 출처 링크가 포함된 후보를 살펴봅니다.
4. 기본적으로 1–3개 스타일을 선택하며, 스타일마다 이미지 한 장을 생성합니다. 명시적으로 요청하면 더 많이 선택할 수 있습니다.
5. 개별 이미지와 나란히 배치된 비교 화면을 확인한 뒤, 스타일 ID를 지정해 수정을 요청합니다.

스타일은 성별 구분 없이 길이와 특징을 기준으로 정리합니다. 목표 사진이 있으면 본인의 모발 조건에 맞게 조정합니다. 이미지를 생성할 때마다 원본 셀카를 본인 외모의 기준으로 사용합니다.

## 실행 환경

이 저장소에는 스킬 지침이 들어 있으며, 이미지 모델, API 서비스 또는 플러그인 구현은 포함되어 있지 않습니다. 로컬 스킬 실행, 이미지 보기, 내장 imagegen 호출을 지원하는 Codex 환경이 필요합니다.

| 도구 | 용도 | 사용할 수 없을 때 |
| --- | --- | --- |
| Codex 내장 imagegen | 헤어스타일 참고 이미지 생성 및 수정 | 제안된 스타일을 보관하고 제한 사항을 설명합니다. 유료 API로 자동 전환하지 않습니다 |
| Exa (선택 사항) | 헤어스타일 자료 검색과 출처 확인에 우선 사용 | 일반 웹 검색으로 전환합니다 |
| TypeSafe (선택 사항) | 후보 설명 텍스트의 선별 및 순위 지정 | Codex가 후보를 선별합니다 |
| Interactive Form Save (선택 사항) | 조건 입력, 복수 선택, 제출된 답변 읽기 | 번호가 있는 선택지와 자유 응답을 사용합니다 |

내장 imagegen을 사용하는 과정에는 `OPENAI_API_KEY` 설정이 필요하지 않습니다. 외부 도구의 가용성, 사용 한도, 이용 약관은 각 서비스에 따르며, 이 저장소는 해당 서비스의 이용 권한을 제공하지 않습니다.

## 설치

이 저장소를 `hairstyle-tryon` 폴더로 복제하거나 압축을 풀어, Codex에 설정된 스킬 디렉터리에 넣습니다.

```text
스킬-디렉터리/
└── hairstyle-tryon/
    ├── SKILL.md
    ├── README.md
    ├── README.zh-CN.md
    ├── README.es.md
    ├── README.fr.md
    ├── README.pt.md
    ├── README.ru.md
    ├── README.ko.md
    ├── README.ja.md
    └── LICENSE
```

`CODEX_HOME`이 설정되어 있다면 그 아래의 `skills` 디렉터리를 사용할 수 있습니다. 설치 전에 같은 이름의 폴더가 있는지 확인하고 기존 수정 사항을 보존하세요. `hairstyle-tryon` 폴더가 두 겹으로 중첩되지 않도록 합니다.

## 사용 방법

Codex에서 스킬을 호출하고 사진을 첨부합니다. 예를 들면 다음과 같습니다.

```text
$hairstyle-tryon으로 평소 출근할 때 어울리는 헤어스타일을 찾아줘.
현재 머리색은 유지하고, 펌은 하지 않고, 매일 손질에 약 5분 정도 쓸 수 있어.
정면 셀카를 올릴게. 먼저 여러 스타일을 고르게 한 다음 참고 이미지를 생성해줘.
```

목표 헤어스타일 사진이 있다면 함께 첨부하고, 특히 유지하고 싶은 특징을 설명하세요. 이후에는 “H02의 앞머리만 조금 더 짧게 하고 나머지는 그대로 유지해줘”처럼 요청할 수 있습니다.

## 결과물

기본 저장 위치는 작업 공간의 `output/hairstyle-tryon/<실행별-고유-ID>/`입니다. 다른 디렉터리를 지정할 수도 있습니다.

- 스타일 ID와 버전으로 이름을 붙인 스타일별 개별 참고 이미지.
- `comparison.html`: 원본 사진과 생성된 이미지를 참조해 나란히 보여주는 비교 페이지.
- `notes.md`: 출처, 생성 프롬프트, 검토 결과, 스타일별 요청 카드.

헤어스타일 요청 카드는 미용사에게 바로 보여줄 수 있는 쉬운 설명입니다. 유지하고 싶은 특징, 허용하는 변화, 평소 손질 습관, 현장에서 확인해야 할 조건을 담습니다. 구체적인 커트 시술 지침이나 결과를 보장하는 문서는 아닙니다.

## 검증 및 이미지 사용

현재 스킬 버전은 `v0.1.0`입니다. 스킬 구조 검사는 통과했으며, 실제 셀카를 사용한 전체 이미지 생성 과정은 아직 검증하지 않았습니다. 생성된 이미지는 시각적 참고용입니다. 실제 커트 가능 여부는 현장에서 모발 상태를 확인해 판단해야 합니다. 본인의 외모를 유지하도록 프롬프트에 제약을 두고 육안으로 검토하지만, 픽셀 단위의 동일성을 보장하지는 않습니다.

저장소에는 스킬과 문서만 포함되어 있으며, 사용자의 셀카나 제3자의 참고 이미지는 없습니다. 실행 중 제공된 사진은 해당 요청에만 사용합니다. 변경 사항을 공개하기 전에 커밋할 파일을 확인해 사진, 생성 결과물, 인증 정보가 포함되지 않도록 하세요. 출력 폴더와 일반적인 로컬 입력 폴더는 `.gitignore`에서 제외하도록 설정되어 있습니다.
